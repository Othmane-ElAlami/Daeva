# Security Policy

## Supported Versions

Currently, we only provide security updates for the latest `master` branch version.

## Reporting a Vulnerability

Security is a priority. If you discover a security vulnerability within Daeva, please do **NOT** file a public issue, as it may contain exploit-sensitive details.

Please report security vulnerabilities privately using [GitHub's private vulnerability reporting feature](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing/privately-reporting-a-security-vulnerability).
If this feature is not yet enabled for the repository, please request the maintainer to enable it via a non-sensitive issue, and withhold the vulnerability details until a secure channel is established.

We will review all reports and do our best to address them in a timely manner.
